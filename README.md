# 💰 Aplikasi Tabungan & Keuangan

Aplikasi mobile modern berbasis Flutter untuk membantu pencatatan transaksi harian, mengelola keuangan, dan memantau target tabungan secara praktis.

---

## 🚀 Fitur Utama

* **Catat Transaksi:** Input pemasukan dan pengeluaran dengan cepat.
* **Target Tabungan:** Pantau alokasi serta *progress* target tabungan harian/bulanan.
* **Manajemen Keuangan:** Ringkasan alur kas untuk mengontrol pengeluaran.
* **Tampilan Modern:** Desain antarmuka responsif dan ramah pengguna.

---

## 🛠️ Teknologi yang Digunakan

* **Framework:** [Flutter](https://flutter.dev/)
* **Language:** [Dart](https://dart.dev/)

---

## 💻 Cara Menjalankan Project

Jalankan perintah berikut di terminal:

```bash
# 1. Clone repository
git clone [https://github.com/Bagas1310/aplikasi-Tabungan-dart.git](https://github.com/Bagas1310/aplikasi-Tabungan-dart.git)

# 2. Masuk ke folder project
cd aplikasi-Tabungan-dart

# 3. Download package/dependencies
flutter pub get

# 4. Jalankan aplikasi
flutter run
